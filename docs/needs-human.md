# Needs-human template

Every needs-human issue or PR Shepherd opens uses this structure. The bot opens one for every escalation, security fixes and routine bumps alike. If an issue for the same problem is already open, the bot comments on it instead of opening a duplicate.

## What happened
One sentence.

## What the bot tried
Short list of attempts, in order.

## What was tested and the result
Build, tests, scans, and their outcomes.

## Risk
`low` | `medium` | `high`, with one sentence of justification.

## Bot recommendation
One sentence.

## One-step actions
- **Approve:** <command or comment>
- **Reject:** <command or comment>
- **Comment with instruction:** <how>
