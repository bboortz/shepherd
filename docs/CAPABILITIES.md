# Capabilities — shepherd

The source of truth for what Shepherd does. Every capability is a mechanical property we can test. Entries are seeded from `docs/DESIGN.md §12`; they become test-linked once the Action lands in Release 1.

Each row: a stable `cap.id`, a one-line description, the source paragraph in DESIGN.md, and — once tests exist — a bidirectional pointer to the acceptance test that proves it. `make verify-traceability` will enforce bidirectional links from R1 onward.

Status values: `design` (described in DESIGN, not implemented yet), `active` (implemented, test-linked), `aspirational` (R2+), `deprecated`.

## Dependabot path (SH-011)

A configurable per-repo baseline: shepherd enforces that managed repos have a well-formed `.github/dependabot.yml`; repos can opt into gated auto-merge of patch/minor Dependabot PRs. Sits alongside `shepherd-bump` — does not replace it (`shepherd-bump` keeps owning the first-party bump path).

| CAP | Description | Source | Status | Test |
|---|---|---|---|---|
| `dependabot.presence-verified` | `shepherd-bump --verify-dependabot` checks `.github/dependabot.yml` exists and is well-formed (`version: 2` + ≥1 `- package-ecosystem:` entry). Exit codes: 0 ok, 3 missing, 4 malformed. | SH-011 | active | `test/acceptance/test_SH_011_dependabot.sh` (fixtures: missing, ok, empty, v1-deprecated, no-updates) |
| `dependabot.config-enforce-opt-in` | `.shepherd.yml` → `dependabot.enforce_enabled` toggles the verifier (default `true`). Setting `false` short-circuits to exit 0 even without a Dependabot config. | SH-011 | active | `test/acceptance/test_SH_011_dependabot.sh` (optout fixture) |
| `dependabot.auto-merge-opt-in-per-repo` | `.shepherd.yml` → `dependabot.auto_merge` toggles the auto-merge workflow (default `false`). Off by default across the fleet; set per repo. | SH-011 | active | `test/acceptance/test_SH_011_dependabot.sh` (schema shape in `templates/shepherd.yml`) |
| `dependabot.auto-merge-level-patch-minor` | Only `patch` + `minor` bumps auto-merge; `major` stays open for human review. Level derived from PR title (`Bump <name> from X.Y.Z to A.B.C`), no third-party action. | SH-011 | active | `test/acceptance/test_SH_011_dependabot.sh` (template inspects `patch` + `minor` tokens; live validation in the SH-011 rollout) |
